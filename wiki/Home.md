# amstrad-cpc-debug

VS Code extension for Z80 source-level debugging of Amstrad CPC programs. It connects to [SugarboxV2](https://github.com/Tom1975/SugarboxV2) via a JSON/TCP debug protocol and implements the Debug Adapter Protocol (DAP), bringing full VS Code debugging features to CPC development.
